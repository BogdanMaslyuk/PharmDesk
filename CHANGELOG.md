# История изменений PharmDesk

## 0.4.4 — 11.11.2026

- Исправлено сопоставление по первому слову, которое давало ложные рекомендации других препаратов из одной торговой линейки.
- Для кандидатов ГРЛС используется полное предварительно выделенное торговое наименование, включая различающие суффиксы.
- Отдельная форма поиска кандидатов также не подменяет «Акридерм ГК» простым «Акридермом».
- При ручной связи импортированной записи с товаром несовпадение полного торгового названия блокируется.
- Данные базы, номера ящиков и импортированный реестр не изменяются. Тесты на случаи комбинаций препаратов.


## 0.4.3 — 05.11.2026

- Исправлено отсутствие видимого результата импорта ГРЛС:
  общий справочник показывает исходные импортированные записи,
  МНН, дату, регистрационные номера, формы и статусы из файла.
- Две вкладки: «ГРЛС: импортированные» и «Подтверждено вручную».
  Поиск по торговому названию, МНН и регистрационному номеру.
- Главная страница и карточки аптечного ассортимента показывают
  объём реестра и явно неподтверждённые варианты сопоставления.
- Диагностика добавляет отдельные счётчики ГРЛС и ручных карточек,
  меню PowerShell показывает фактическую версию.
- Без переноса, удаления или автоматического сопоставления исходных данных.


## 0.4.2 — 05.11.2026

- Кнопка прямой загрузки ZIP с официальной страницы ГРЛС:
  найденная на странице ссылка формируется динамически, её не нужно
  копировать вручную.
- Безопасный HTTPS, проверка домена/переадресаций, размера и структуры ZIP.
- Перед импортом по-прежнему нужен предварительный просмотр и явное
  подтверждение; локальные товары и ручные связи не изменяются.
- Загрузчик исправлен по реальному восьмикнижному архиву:
  добавлен статус «Изменённый», пропускаются категории/итоговые строки,
  сохраняются очень длинные описания форм выпуска и отмечаются
  исходные записи без формы.
- Подготовлены проверки синтетических и полного официального архива.

**При ограниченном доступе к Минздраву на компьютере автоматическая
загрузка может не пройти; ручной импорт оригинального ZIP сохранён.**


## 0.4.1 — 05.11.2026

- Загрузка ZIP с документированными XLSX-файлами ГРЛС.
- Предварительный просмотр даты, статусов, контрольной суммы SHA-256
  и записей без изменения базы.
- Явное подтверждение импорта в два изолированных реестровых источника:
  `grls_import_batches` и `grls_import_rows`.
- Поиск по номеру удостоверения и торговому названию, фильтры
  по статусу и дате снимка; отдельная страница происхождения строки.
- Поиск потенциальных совпадений с товаром без автоматической привязки.
  В ручную форму переносятся только регистрационный номер и торговое название.
- Ограничение ZIP/XLSX, защита от повреждённых архивов,
  неизвестных статусов и повторного импорта.
- Документация ограничений достоверности источника.

**Нет прямой синхронизации с сайтом, подтверждения оригинальности
выгрузки или автоматического назначения замен.**


## 0.4.0 — 05.11.2026

- Отдельный справочник регистрационных карточек с номером регистрации,
  торговым названием, лекарственной формой, дозировкой, производителем,
  официальной ссылкой и датой ручной сверки.
- Таблицы действующих веществ и состава зарегистрированного препарата,
  отделённые от неподтверждённых значений в товарном каталоге.
- Ручное связывание товарной карточки с конкретной формой/дозировкой,
  обязательные подтверждения и объяснение несовпадений.
- Отмена связи с сохранением причины, неизменяемая история действий
  и повторная привязка только после явного решения.
- Защита картотеки от удаления при полной замене ассортимента;
  никаких автоматических фармакологических выводов.
- Обновлены форма прежних ручных источников, документация и тесты.

**ГРЛС и ЕАЭС не загружаются автоматически; сведения остаются ручными
и не подтверждают актуальный регистрационный статус.**


## 0.3.2 — 05.11.2026

- Точное совпадение по коду и названию всегда важнее похожего написания.
- Поиск при отсутствии точного результата предлагает отдельные
  **приблизительные совпадения** с одной опечаткой в русском названии;
  коды, числа и короткие слова не корректируются автоматически.
- В каталоге и подсказках приблизительные результаты явно помечены.
- Новый читающий раздел «Контроль качества каталога» с фильтрами,
  предупреждениями о латинице, смешанных алфавитах и возможных дублях.
- Добавлены тесты безопасности поиска, фильтров по ящикам и отсутствия
  изменений товарных данных от просмотра отчёта.
- Локальная схема SQLite и существующие ручные подтверждения не затронуты.

**Ни один результат приблизительного поиска не означает терапевтическую
взаимозаменяемость или достоверность фармакологических сведений.**


## 0.3.1 — 04.11.2026

- Единое меню Windows PowerShell: запуск, обновление, резервная копия, диагностика и тесты.
- Согласованные снимки SQLite вместе с локальными фотографиями; ZIP с SHA-256.
- Читающая диагностика SQLite, схемы таблиц, ящиков, товаров и источников фото.
- Полная остановка безопасного обновления при локальных изменениях и занятом порту 8000.
- Прогресс проверки по ящикам и увеличение исходного снимка до 400%.
- Дополнительная защита от отката подтверждённого препарата при ручном изменении кода.
- Отдельный счётчик защищённых записей во время CSV/Excel-импорта.
- Документированы ограничения и архитектурный план справочника v0.4.

**Данные аптеки не пересылаются в GitHub. Восстановление из копии остаётся ручной операцией.**


## 0.3.0 — 03.11.2026

- Очередь ручной проверки 1 433 позиций из исправленной книги с приоритетом для 308 сомнительных.
- Импорт исходных фотографий из ZIP только в локальное хранилище.
- Отображение источника, номера строки и прежнего названия на отдельной странице.
- Подтверждение, исправление и исключение товара с защитой от действий без исходного фото.
- История ручных решений и статус сверки в ящиках и поиске.
- Защита подтверждённых вручную данных от возврата старых OCR-ошибок при следующем импорте.
- Подготовлена модель и форма документального ручного сопоставления действующих веществ с инструкциями ГРЛС.
- При обновлении Windows скрипт сохраняет резервную копию фотографий в дополнение к SQLite.

**Ограничения:** ни одно название не считается подтверждённым просто из-за совпадения двух OCR. Показания, противопоказания, аналоги и взаимодействия автоматически не формируются.


## 0.2.0 — 30.10.2026

- Создание и редактирование ящиков в веб-интерфейсе.
- Добавление, редактирование и удаление товарных позиций; явное подтверждение удаления.
- Перенос записей между ящиками с защитой от конфликтов кодов.
- Предварительная проверка и массовый импорт CSV/XLSX из нескольких ящиков одной операцией.
- Повторный импорт обновляет товар с прежним кодом в том же ящике и не удаляет отсутствующие строки.
- Исправлен поиск по русским названиям: независимость от регистра, «е/ё», несколько слов; фильтр по ящику.
- Быстрые подсказки поиска.
- Локальный журнал ручных изменений и импортов.
- Защита изменяющих форм одноразовым для сессии CSRF-токеном.
- Дополнительные тесты импорта и операций управления.
- Обновлённая инструкция для перехода с версии 0.1.

**Ограничения:** локальный запуск без авторизации, неподтверждённые остатки, нет внешней лекарственной базы и проверки взаимодействий. Не предназначено для принятия медицинских решений.

## 0.1.0

- Карта ящиков, каталог товаров, локальный поиск, карточки и базовая SQLite-база.
