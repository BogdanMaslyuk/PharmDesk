# План PharmDesk v0.4 — проверенный фармакологический справочник

Этот документ — подготовка архитектуры, **не реализованная автоматическая база**.

## Существующие сущности

- Drawer: место хранения.
- StockItem: товарная позиция с кодом, ящиком и источником.
- Medicine: текущая карточка товара с названием и производителем;
  сейчас не должна трактоваться как точный регистрационный препарат.
- Ingredient: действующее вещество, сейчас только для учебных данных и ручной связи.
- SubstanceEvidence: внесённая человеком ссылка на инструкцию ГРЛС;
  она не создаёт автоматически Ingredient и не разрешает подбор замены.
- ClinicalRecord: клинические сведения, выводимые только при флаге проверки.

## Предлагаемое разделение для следующего релиза

1. Товар аптеки: внутренний код, название из учётной системы,
   конкретная упаковка, ящик, источник, статус сверки.
2. Зарегистрированный лекарственный препарат: регистрационный номер,
   торговое наименование, производитель, форма выпуска, дозировка,
   номер документа или инструкции, дата проверки.
3. Действующее вещество: стандартизированное МНН/номенклатура, количественный
   состав и источник. Привязка возможна только после идентификации
   зарегистрированного препарата.
4. Источник: официальное название, URL, дата доступа, версия документа,
   ответственное лицо, статус проверки; история изменений не стирается.

## Проверяемый процесс

Товар -> предлагаемый зарегистрированный препарат -> ручная сверка
регистрационного номера/формы/дозировки -> подтверждённое действующее
вещество -> проверенные сведения инструкции.

Не выводить взаимозаменяемость из одного МНН без проверки формы,
дозировки, режима применения и юридически применимых ограничений.
Не определять лекарственные взаимодействия из свободного текста
без специализированного клинического источника.

## Критерии внедрения

- Схемы данных с обратимой миграцией и резервной копией.
- Список подтверждённых официальных источников и лицензий.
- Отдельные статусы «не определено», «предложено», «проверено».
- Сверка уникальных идентификаторов и коллизий названий.
- Сильные тесты на однофамильные торговые названия, формы, дозировки
  и комбинации действующих веществ.
- Безопасное поведение при отсутствии подтверждения: сведения не выводятся,
  а система не предлагает лечебную замену.
