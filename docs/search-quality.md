# PharmDesk v0.3.2 — поиск с учётом опечаток и контроль качества каталога

## Назначение

Обновление облегчает поиск товаров аптеки, но не определяет достоверность
названия препарата автоматически. Все выводы о возможных ошибках
предназначены только для проверки человеком.

## Поиск

- Работает в разделе «Препараты», в отдельных ящиках и при вводе подсказок.
- Сначала ищет **точные** совпадения по товарному коду, наименованию,
  производителю и ранее сопоставленным справочным полям.
- При наличии точных совпадений приблизительные результаты **не показываются**.
- Если точного совпадения нет, ищет полные кириллические слова в названии
  товара с **не более чем одной опечаткой**.
- Для коротких слов (меньше 5 букв), чисел, дозировок и кодов
  приблизительное сопоставление запрещено.
- Пример: «бетагестин» может найти «бетагистин»,
  если точного «бетагестин» в базе нет.
- Пример: код 417157 не будет автоматически исправлен на 417158.
- Все найденные по опечатке позиции помечены
  **«Похоже по написанию»** — это не подтверждение,
  не определение действующего вещества и не медицинская рекомендация.
- Поиск всегда использует только локальный ассортимент.

## Контроль качества

Открыть «Управление» → «Качество каталога» или адрес
http://127.0.0.1:8000/manage/quality.

Отчёт читает локальные записи и отмечает:

1. Латинские буквы в товарном названии, когда название не подтверждено по фото.
2. Смешение русского и латинского алфавитов внутри слова.
3. Повторяющиеся символы, маркеры повреждённого OCR и неизвестные названия.
4. Одинаковые наименования от одного производителя в одном ящике
   при разных кодах.
5. Один код в разных ящиках при разных названиях товара.

Это **эвристические признаки**, а не доказательства ошибки.
Правильные торговые названия иногда пишутся латиницей; несколько кодов
могут иметь законную причину. Отчёт не делает вывод о регистрации,
взаимозаменяемости или количестве товара.

По каждой строке можно перейти к ручной сверке фотографии (если очередь
содержит источник) или открыть карточку редактирования товара.
Из отчёта **нельзя автоматически исправить или удалить** запись.

## Защита данных

Изменений структуры SQLite нет, новых миграций нет.
При открытии отчёта база только читается. Поиск тоже ничего не записывает.

Проверенные вручную позиции сохраняют свои статусы;
раздел сверки по фотографиям работает как прежде.
При обновлении кода используйте уже существующее меню PowerShell и
резервное копирование из v0.3.1.

## Ограничения и следующее развитие

Нет поиска по терапевтической группе без проверенных источников.
Нет автоматического определения МНН, дозировок, противопоказаний,
аналогов или взаимодействий.
Фармакологический справочник будет отдельным этапом v0.4.
