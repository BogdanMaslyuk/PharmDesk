# PharmDesk — рабочее место фармацевта

Веб-приложение для поиска лекарств по ящикам, товарным кодам и действующим веществам. На первом этапе — локальный учебный прототип.

## Возможности первой версии
- Карта ящиков и просмотр ассортимента;
- Поиск препаратов по наименованию и коду;
- Учёт торгового наименования, дозировки, производителя;
- Импорт CSV и Excel через Python;
- Интерфейс карточки препарата;
- Заглушка взаимодействий: **не проводит медицинскую проверку**.

## Установка (Python 3.11+)
```sh
python -m venv .venv
pip install -r requirements.txt
python -m app.cli seed-demo
uvicorn app.main:app --host 127.0.0.1 --port 8000
```
Откройте http://127.0.0.1:8000

## Принципы безопасности
- Демо-данные **вымышлены**. Не публикуйте реальные аптечные выгрузки, секреты, сведения о клиентах.
- Наличие товарной позиции в каталоге не подтверждает остатки на складе.
- **Проверка лекарственных взаимодействий не реализована.** Отсутствие результата никогда не означает безопасность комбинации.
- Приложение запускается локально и не подготовлено к публикации в интернете или применению для клинических решений.
- В будущем нужны проверенные лицензированные источники лекарственной информации, контроль качества и авторизация.

## Ближайший план
1. Поддержка нескольких ящиков и безопасного повторного импорта ассортимента.
2. Проверенные карточки действующих веществ и лекарственных форм, ссылки на инструкции.
3. Аналоги по действующему веществу отдельно от терапевтических альтернатив.
4. Подключение проверенного источника взаимодействий, тестирование.
5. Права доступа, журнал изменений, резервное копирование и развёртывание.
