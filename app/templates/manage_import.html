Импорт ассортимента

Загрузите один файл со всеми ящиками или выгрузку одного ящика.

Выберите файл

Размер до 4 МБ, до 3000 строк. Файл хранится локально в вашем браузере до отправки на ваш компьютер.

Результат проверки

Проверьте файл перед импортом. До подтверждения данные не меняются.

Столбцы «Код» и «Наименование товара» обязательны. «Ящик» можно указать для каждой строки или выбрать один номер сверху. Повторный импорт обновляет совпадения по коду внутри того же ящика, не удаляя записи, отсутствующие в новом файле.

Предупреждение: не загружайте сюда персональные данные покупателей. Не публикуйте реальные аптечные выгрузки на GitHub, даже если они открываются в локальном приложении.
